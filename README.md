Web para servidores de Minecraft hecha con React y Vite.

## Instalar

```bash
unzip BlockHub.zip
cd BlockHub
npm install
```

## Desarrollo

```bash
npm run dev
```

## Compilar

```bash
npm run build
```

La carpeta `dist/` queda lista para cualquier hosting estático.

## Configuración

Editar `src/config.js` (nombre, IP, rangos, staff y FAQ).

## Despliegue

En el repo: Settings → Pages → Source: GitHub Actions. Cada push a `main` publica la web.
